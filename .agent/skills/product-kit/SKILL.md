# Product kit

1. Read `AGENTS.md` first. It is binding; this kit never overrides it.
2. Run `node .agent/product-kit/kit.mjs continue` and do what it prints. When the founder says "continue", that is all you need.
3. Follow `.agent/product-kit/MASTER_PROMPT.md` and `.agent/product-kit/PROTOCOL.md`.
4. Never push, deploy, or install third-party tools without the founder's explicit instruction.
5. Record founder decisions only with the founder's own words (`decide`, `ack`).
