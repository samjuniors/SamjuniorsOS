## Plan
1. Extend `SafeModeManager` in `src/lib/server/sophia/stop-control.ts`:
   - Add active worker registration (`registerActiveWorker`, `unregisterActiveWorker`).
   - Abort all active workers in `triggerStop()`.
   - Record frozen state and immutable audit logging.
2. Upgrade `ServerAgentExecutor` (`src/lib/server/agents/executor.ts`):
   - Add AbortSignal event listening during `generateJson` so mid-run aborts immediately halt the worker.
   - Record run with `status: 'halted'`, duration, and error in `AgentRunStore`.
3. Upgrade `WorkflowRuntime` (`src/lib/server/workflow/runtime.ts`):
   - Register executing step with `SafeModeManager.registerActiveWorker`.
   - Halt mid-run steps when stop is triggered, transitioning state to `cancelled`/`halted` and recording state.
4. Integrate Safe Mode into `AutonomyPolicyEngine` (`src/lib/server/authorization/autonomy-policy.ts`):
   - When `SafeModeManager.isFrozen()`:
     - `read` action class permitted (drops to read-only mode).
     - All other action classes (`draft`, `internal_write`, `external_reversible`, `external_hard_to_reverse`, `financial_legal`, `destructive_security`) return `needs_approval` / `forbidden` with `SAFE_MODE_ACTIVE_AUTONOMY_FROZEN`.
5. Integrate Safe Mode into `SideEffectPolicyEvaluator` (`src/lib/server/authorization/policy-evaluator.ts`):
   - When `isFrozen()`: `read_only` permitted, mutations denied with `DENIED_SAFE_MODE_FROZEN`.
   - Add `'DENIED_SAFE_MODE_FROZEN'` to `AuthorizationReasonCode` in `src/types/authorization.ts`.
6. Update `executeSophiaTurn` in `src/lib/server/sophia/turn-executor.ts`:
   - Support read-only queries during safe mode while strictly refusing mutations and autonomous actions.
7. Author comprehensive drill test suite `tests/sophia/g12_7_kill_switch_safe_mode.test.ts`.
8. Run full test runner, typecheck, lint, build.
9. Independent reviewer verification.

## What changed
- `src/lib/server/sophia/stop-control.ts`:
  - Added active worker tracking (`activeWorkers: Map<string, AbortController>`) with `registerActiveWorker`, `unregisterActiveWorker`, and `getActiveWorkersCount`.
  - In `triggerStop()`, immediately abort all registered active workers with `AbortController.abort()`, recording `haltedWorkersCount` in state, audit entry, and stop results.
  - Added `haltedWorkersCount` to `FreezeState` and `StopControlResult`.
- `src/lib/server/agents/executor.ts`:
  - Added Safe Mode check before task execution in `ServerAgentExecutor.executeAgentTask`: fails closed immediately and records `status: 'halted'` when Safe Mode is active.
  - Implemented mid-run AbortSignal race against `generateJson`: aborts in-flight worker execution immediately upon stop control trigger.
  - Recorded aborted runs in `AgentRunStore` as `status: 'halted'` with duration, error, and unverified provenance.
- `src/lib/server/workflow/runtime.ts`:
  - Integrated `SafeModeManager.registerActiveWorker` and `unregisterActiveWorker` during `WorkflowRuntime.executeReadyStep`.
  - Passed `stepAbortController.signal` into `executeAgentTask`.
  - Handled mid-run stop abortion by cleanly transitioning step state to `'cancelled'` with error documentation, updating instance state without hung promises.
- `src/lib/server/authorization/autonomy-policy.ts`:
  - Integrated Safe Mode check into `AutonomyPolicyEngine.evaluate`: when Safe Mode is active, `read` actions remain permitted (`SAFE_MODE_READ_ONLY_PERMITTED`), while all other action classes (`internal_write`, `external_reversible`, `financial_legal`, etc.) return `needs_approval` / `forbidden` with `SAFE_MODE_AUTONOMY_FROZEN`.
- `src/lib/server/authorization/policy-evaluator.ts`:
  - Integrated Safe Mode check into `SideEffectPolicyEvaluator.evaluate`: when Safe Mode is active, `read_only` operations are allowed (`READ_ONLY_ALLOWED`), while all side-effect mutations are denied with `DENIED_SAFE_MODE_FROZEN`.
- `src/types/authorization.ts`:
  - Added `'DENIED_SAFE_MODE_FROZEN'` to `AuthorizationReasonCode`.
- `src/lib/server/activity/projection.ts`:
  - Guarded `truncate` and `instanceWorkstreamOf` against undefined/missing `instance.objective` preventing null dereference crash during activity projection under test runner.
- `tests/sophia/g12_7_kill_switch_safe_mode.test.ts`:
  - Authored comprehensive 6-phase drill suite testing:
    - Phase 1: Voice & Panel trigger recognition activating Safe Mode.
    - Phase 2: Mid-run worker halting drill with `AgentRunStore` state recording (`status: 'halted'`).
    - Phase 3: Mid-run workflow step halting drill with `WorkflowStore` state recording (`status: 'cancelled'`).
    - Phase 4: Safe Mode read-only enforcement (read permitted, mutations blocked in autonomy policy and side-effect gate, 0 scheduled jobs executed).
    - Phase 5: Zero model dependency drill (100% deterministic operation and unfreeze when model provider is completely dead).
    - Phase 6: Tamper-evident audit trail verification.

## Why

- Guarantees fail-closed safety and read-only operation even during external model provider outages.
