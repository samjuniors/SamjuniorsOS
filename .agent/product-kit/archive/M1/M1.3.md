# M1.3: Scope-aware context: personal questions read only the Personal Mind, company questions read only the Company Brain with sources, and nothing found gives an honest 'I do not remember'

Exit evidence required: A planted personal fact never appears in a company answer (test); each answer lists the scopes it read and its sources; an empty result abstains.

   - `src/lib/server/sophia/types.ts`: Define `MemoryScope = 'personal_mind' | 'company_brain'`, extend `SophiaAssembledContext`, `SophiaTurnResult`, `SophiaExecutionResult`, and `ValidatedSophiaCommand` with `scopes` and `sources`.
   - `src/lib/server/sophia/context-assembly.ts`: Add `scope?: 'all' | 'personal_only' | 'company_only' | 'none'` to `SophiaContextAssembler.assemble()`. Partition slices strictly so `company_only` never evaluates or includes `PERSONAL_MIND_MEMORY` (even when `founderId` is present); `personal_only` includes exclusively `PERSONAL_MIND_MEMORY`; `none` yields zero slices; `all` retains full backward compatibility.

Enforce honest abstention for empty Personal Mind queries. Append `[Scopes: ... | Sources: ...]` footer to factual answers and forward `scopes` and `sources` on turn results.

   - `src/lib/server/sophia/sofiaui.ts` & `src/app/api/sofia/ask/route.ts` & `src/sofia/sophia/*`: Propagate `scopes` and `sources` across SofiaUI endpoint and client state models.

## What changed
1. `src/lib/server/sophia/types.ts`:
   - Exported `MemoryScope = 'personal_mind' | 'company_brain'`.
   - Added `scopes?: MemoryScope[]` and `sources?: string[]` to `SophiaAssembledContext`, `SophiaExecutionResult`, `SophiaTurnResult`, and `ValidatedSophiaCommand`.
2. `src/lib/server/sophia/context-assembly.ts`:
   - Added `scope?: 'all' | 'personal_only' | 'company_only' | 'none'` parameter to `SophiaContextAssembler.assemble()`.
   - Enforced partition rules: `company_only` strictly sets `includePersonal = false` (guaranteeing personal notes never enter company context prompt); `personal_only` sets all company slices to false; `none` disables all context slices; `all` maintains backward compatibility.
   - Set `context.scopes` and `context.sources` deterministically on the assembled context.
3. `src/lib/server/sophia/turn-executor.ts`:
   - Evaluated route prior to context assembly to assign deterministic context scope partition.
   - Handled empty Personal Mind results directly with honest abstention: `I do not remember any personal notes or preferences regarding that.` with `[Scopes: personal_mind | Sources: SophiaMemoryStore]`.
   - Enforced `scopes` and `sources` propagation into turn records and response objects.
4. `src/lib/server/sophia/server-gateway.ts`:
   - Attached `scopes` and `sources` to all informational query branches.
   - Added honest abstention for missing company facts and missing personal memories.
   - Guarded `activitySlice` fallback so general company questions with no matching knowledge return honest abstention instead of dumping irrelevant activity logs.
5. `src/lib/server/sophia/intent-classifier.ts`:
   - Updated `isKnowledgeQuery` patterns to include `protocol`, `specification`, and `spec` for reliable deterministic routing of company questions.
6. `src/lib/server/sophia/sofiaui.ts`, `src/app/api/sofia/ask/route.ts`, `src/sofia/sophia/control.ts`, `src/sofia/sophia/types.ts`:
   - Forwarded `scopes` and `sources` across HTTP responses and SofiaUI state turns.
7. `tests/sophia/m1_3_scope_aware_context.test.ts`:
   - Authored 11 comprehensive tests across 5 groups covering fact isolation, scope/source listing, empty abstention, context partitioning, and SofiaUI client seam.
