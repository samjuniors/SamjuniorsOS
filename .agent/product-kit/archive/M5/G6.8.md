## What changed
1. Strict Source Isolation Engine (`src/lib/server/sophia/briefing.ts`):
   - Implemented `getProactiveBriefing(opts)` querying strictly `DecisionLogStore` and `InMemoryApprovalStore`.
   - Never references web scraping, external social media, or synthetic company claims.
   - Enforces strict sources tuple `['DecisionLogStore', 'InMemoryApprovalStore']`.
   - Generates both concise spoken text (1–3 sentences) and structured markdown text.
   - Honest empty state plainly states: *"No decisions or approval changes have been recorded since your last session... All systems are standing by."*
   - Latency budget is deterministic and measured under 50ms.
2. Briefing Settings Store (`BriefingSettingsStore`):
   - Persists `{ enabled: boolean, spokenOnOpen: boolean, includeDecisions: boolean, includeApprovals: boolean }`.
   - When `enabled: false`, `getProactiveBriefing` returns `{ success: true, enabled: false, briefing: null, disabledReason: '...' }`, suppressing auto-briefings across UI and voice.
3. Conversational and Voice Routing:
   - In `src/lib/server/sophia/stop-control.ts`: Enhanced `isStopCommand` to recognize `"stop briefing"`, `"pause briefing"`, `"cancel briefing"`, `"stop talking"`, and `"quiet"`, immediately freezing turns and activating Safe Mode.
   - In `src/lib/server/sophia/intent-classifier.ts`: Added `isBriefingQuery` and `isBriefingSettingsCommand`.
   - In `src/lib/server/sophia/turn-executor.ts`: Deterministically handles explicit briefing inquiries and natural language voice/text toggle commands (e.g. "turn off proactive briefing", "enable briefing").
4. Unified UI Controls:
   - In `src/os/components/os/DesktopOS.tsx`: Added "Proactive Briefing" toggle switch (`data-testid="toggle-proactive-briefing"`) under Settings popover (`pop === "settings"`).
   - In `src/os/components/voice/SharedSophiaVoicePresence.tsx`: Rendered Proactive Briefing card (`data-testid="sofia-briefing-card"`) with action buttons, dismiss button, and "Turn off briefings" toggle.
   - In `src/os/App.tsx`: Automatically fetches proactive briefing upon session open using `lastSessionAt`.
5. Automated Regression Test Suite (`tests/sophia/g6_8_proactive_briefing.test.ts`):
   - 12 comprehensive checks covering source isolation, honest empty state, real change synthesis, settings persistence & API routes, voice barge-in stop control, natural dialogue turns, and latency budget (all passed).
