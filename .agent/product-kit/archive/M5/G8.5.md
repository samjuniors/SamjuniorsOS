## What changed
1. Created `src/os/lib/errorFormat.ts`:
   - `formatUserError(error, fallback)`: strips stack traces, file paths, TypeError prefixes, and URLs, structuring all errors into honest `whatHappened` and `whatToDo` guidance.
   - `isRawError(text)`: validates that raw technical strings are detected and suppressed.
2. Upgraded `ErrorState` in `src/os/components/surfaces/StandardSurfaces.tsx`:
   - Renders formatted `whatHappened` and `whatToDo` copy with optional retry action.
   - Strips raw error strings before rendering.
3. Created `src/os/components/surfaces/ErrorBoundary.tsx`:
   - Catches unhandled React errors in child components and displays dignified recovery guidance with "Reload Workspace" and "Attempt Recovery" actions.
   - Wrapped Cockpit `<main>` in `src/os/App.tsx`.
4. Hardened surfaces across the OS:
   - `FlowDesktop.tsx`: added explicit actionable guidance (`action`) to `AttentionList`, `DecisionList`, `ApprovalList`, and `CompanyActivityList`; sanitized Graph 503 fail-closed banner and automation schedule form errors.
   - `ChatPanel.tsx`: sanitized agent chat error fallback with `formatUserError` (`⚠ What happened: ... What to do: ...`); improved empty thread guidance.
   - `Spotlight.tsx`: enhanced empty search results state ("Try a different keyword, or press ESC to dismiss.").
   - `SharedSophiaVoicePresence.tsx`: sanitized microphone and voice initialization errors into clear instructions ("Allow microphone access in browser settings, or use the text chat panel below.").
   - `TodoDrawer.tsx`: added inline directive dispatch failure banner with actionable retry guidance.
   - `SophiaPanel.tsx`: clarified memory review queue error state with retry guidance.
5. Authored comprehensive test suite `tests/frontend/g8_5_copy_empty_states_errors.test.ts` (16/16 checks passing).

## Why
Per `AGENTS.md` and G8.5 exit requirements, the company operating system must never display raw exceptions, stack traces, or cryptic technical codes to the founder. Every error state must state what happened and what to do.
