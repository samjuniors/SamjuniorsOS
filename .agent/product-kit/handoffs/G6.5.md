## What changed
1. Created `src/os/lib/presence.ts`:
   - Defined `VoicePresenceState`: `'offline' | 'mic_blocked' | 'voice_unavailable' | 'connecting' | 'listening' | 'thinking' | 'speaking' | 'interrupted' | 'voice_off'`.
   - Implemented pure deterministic resolver `resolvePresenceState(opts: PresenceStateOptions): PresenceStateInfo`.
   - Guaranteed honest reporting: offline network or status maps to `'offline'` ("Offline"), permission denial maps to `'mic_blocked'` ("Microphone blocked"), provider errors map to `'voice_unavailable'` ("Voice unavailable"), without masquerading as idle or live.
2. Updated `src/os/lib/osStore.ts`:
   - Added `chatPanelOpen: boolean` and `chatPanelContactId: string` to `OSState` and `SEED`.
   - Added `os.openChatPanel(contactId?: string)`, `os.closeChatPanel()`, and `os.toggleChatPanel(contactId?: string)`.
3. Upgraded `src/os/components/voice/SharedSophiaVoicePresence.tsx`:
   - Integrated `resolvePresenceState` with browser `online` and `offline` event listeners.
   - Rendered honest presence badge with state-derived styling and ARIA attributes (`data-testid="presence-status-badge"`).
   - Added prominent panel fallback button (`data-testid="presence-panel-fallback-btn"`) whenever voice is unavailable or offline, transitioning user directly to text chat with Sophia via `os.openChatPanel("sophia")`.
   - Guarded mic toggle to honestly inform founder when offline and prevent dead clicks.
4. Upgraded `src/os/components/voice/VoiceStatusPill.tsx`:
   - Added `isOffline` and `isVoiceUnavailable` props.
   - Displayed truthful labels: `"Offline · Text Chat Available"` and `"Voice Unavailable · Click for Text"`.
5. Enhanced `src/os/components/os/ChatPanel.tsx`:
   - Synchronized panel visibility and active contact with `osStore` (`storeChatOpen`, `storeContactId`).
   - Added offline fallback banner (`data-testid="chat-offline-banner"`), stating: `"Offline mode · Voice unavailable · Queries use deterministic local fallback"`.
6. Authored comprehensive test suite `tests/frontend/g6_5_presence_states_and_fallback.test.ts` (13/13 PASS):
   - Proved `offline` presence state when network or status is offline.
   - Proved `mic_blocked` presence state when microphone permission is denied.
   - Proved `voice_unavailable` presence state on provider/gateway error.
   - Proved `connecting`, `listening`, `thinking`, `speaking`, `interrupted`, and `voice_off` presence states.
   - Proved `osStore` panel fallback open/close/toggle actions.
   - Proved static AST contracts across `SharedSophiaVoicePresence`, `ChatPanel`, and `VoiceStatusPill`.
