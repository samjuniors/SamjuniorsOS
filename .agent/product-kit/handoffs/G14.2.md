Needed: Secure, stateless MCP client sitting strictly behind `CapabilityGateway` so external MCP servers are vetted, limited, and audited without bypassing governance.
Already in codebase: `CapabilityGateway` (`src/lib/server/capabilities/capability-gateway.ts`), `CapabilityRegistry` (`src/lib/server/capabilities/capability-registry.ts`), `InMemoryAuditStore` (`src/lib/server/authorization/approval-store.ts`), and `SideEffectAuthorizationGate` (`src/lib/server/authorization/gate.ts`).

## What changed
- Created `src/types/mcp.ts`: Authoritative constants (`MCP_CURRENT_SPEC_REVISION = '2026-07-28'`), JSON-RPC 2.0 schemas, transport types, and tool result schemas.
- Created `src/lib/server/capabilities/mcp-transports.ts`:
  - `McpMemoryTransport`: High-performance in-memory fake server for fast deterministic tests.
  - `McpStdioTransport`: Robust child-process stdio transport with newline framing, request ID mapping, and timeout guards.
- Created `src/lib/server/capabilities/mcp-client.ts`: `McpClientAdapter` managing self-contained calls with `_meta: { protocolVersion: '2026-07-28', requestId: '...' }`.
- Created `scripts/mcp-sample-server.mjs`: Reference stdio server implementing `tools/list` (`sqlite_query`, `system_echo`) and `tools/call`.
- Updated `src/lib/server/capabilities/capability-gateway.ts`: Wired `mcp_stdio` and `mcp_sse` entrypoints to execute through `McpClientAdapter`, ensuring every call passes autonomy policy, founder approval gates, and saves an immutable audit record to `InMemoryAuditStore`.
- Created `tests/capabilities/g14_2_mcp_client_gateway.test.ts`: 12 comprehensive automated tests covering spec revision confirmation, fake server, real stdio server, self-contained calls, and gateway audit trail.

## Why
Upholds `AGENTS.md` Sections 3, 4, 11, and 13. Connecting MCP tools directly to models or background workers without gateway mediation violates fail-closed security and auditability invariants. Placing MCP strictly behind `CapabilityGateway` guarantees policy enforcement, founder approval on side effects, and immutable audit logs.
