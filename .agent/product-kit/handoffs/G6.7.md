## What changed
1. Authored Written Persona Specification in `docs/SOPHIA_PERSONA_SPECIFICATION.md`:
   - Defined Sophia Vance, Chief Operating Officer: executive peer, operational compass, authoritative partner.
   - Enforced Single Persona Invariant (`AGENTS.md` §3, §6): Voice, chat, and spotlight speak with one unified voice and memory.
   - Defined Vocal Style: spoken turns default to 1–3 concise sentences, zero conversational filler ("Sure thing!", "I'd love to help!"), transparent and direct.
   - Enforced Anti-Fabrication Invariants: Zero confabulation of personal or company memory; missing state receives an honest "I do not remember" abstention; unrecorded actions are plainly stated as not recorded.
   - Established Governance Boundary: Voice sessions can propose or steer, but never approve consequential mutations or bypass `SideEffectAuthorizationGate`.
2. Created Canonical Code Persona in `src/lib/server/sophia/persona.ts`:
   - Exported `SOPHIA_PERSONA_SPEC`, `SOPHIA_CORE_SYSTEM_INSTRUCTION`, `SOPHIA_VOCAL_STYLE`.
   - Exported `getUnifiedSophiaPrompt({ channel, tone })` which returns the single unified instruction tailored with channel-specific format rules (spoken conciseness for voice, structured markdown for chat).
   - Exported `evaluateMemoryFabrication(query, reply, groundTruth)` which programmatically detects hallucinations, invented facts, or false affirmations against empty ground truth, failing builds when fabricated memories occur.
3. Unified Prompts Across Codebase:
   - `src/lib/server/agents/definitions.ts`: Updated `SERVER_AGENTS.coo` to use `SOPHIA_CORE_SYSTEM_INSTRUCTION`.
   - `src/lib/server/live/providers/gemini-provider.ts`: Replaced divergent `PERSONA_PROMPTS` (`creative`, `technical`, `friendly`) with `getUnifiedSophiaPrompt({ channel: 'voice' })`.
   - `src/lib/server/sophia/intent-classifier.ts`: Added memory query patterns (`/\bwhat did i (say|tell you|mention|write|ask)\b/i`) to `isPersonalQuery`.
   - `src/lib/server/sophia/stop-control.ts`: Added trailing modifier support (`immediately|right now`) to `isStopCommand`.
4. Curated Persona Evaluation Benchmark:
   - `benchmark/persona/types.ts`: Defined `PersonaTestCase`, `PersonaTurnEvaluation`, `PersonaEvaluationRunResult`.
   - `benchmark/persona/labelled-set.json`: Authored 14 evaluation cases across 5 categories (`anti_fabrication_refusal`, `conciseness_and_naturalness`, `voice_chat_consistency`, `grounded_recall`, `governance_boundary`).
   - `benchmark/persona/evaluate.ts`: Benchmark engine executing turns against `executeSophiaTurn` and writing baseline results.
   - `docs/benchmarks/2026-10-30-persona-and-anti-fabrication-baseline-g67.md` & `benchmark/persona/results/baseline.json`: Recorded baseline achieving **14/14 PASS (100%), 0 fabrications, 100% refusal accuracy on ungrounded queries**.
5. Built Automated Regression Suite in `tests/sophia/g6_7_persona_and_fabricated_memory.test.ts` (10/10 PASS):
   - Group 1: Single unified persona invariant (authoritative identity, voice/chat instruction sharing, zero drift).

   - Group 3: Anti-fabrication invariant for Company Brain (imaginary Series B triggers honest refusal).

   - Group 6: Conciseness & naturalness invariant (voice turns concise, zero sycophancy).
   - Group 7: Governance boundary (voice approval attempts on consequential side effects are strictly rejected).
