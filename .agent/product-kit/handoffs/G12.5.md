## What changed
1. **Authoritative Clarification Thresholds (`src/types/decision.ts`, `src/lib/server/sophia/types.ts`)**:
   - Defined `DEFAULT_ROUTE_CLARIFICATION_THRESHOLDS` mapping each route to its confidence threshold:
     - `propose-for-approval`: 0.80
     - `schedule`: 0.75
     - `delegate`: 0.75
     - `use-tool`: 0.70
     - `refuse`: 0.70
     - `recall-company`: 0.65
     - `recall-personal`: 0.65
     - `research`: 0.65
     - `converse`: 0.60
     - `ask-clarify`: 0.00
   - Implemented `getRouteClarificationThreshold(route, overrides)` supporting custom threshold overrides per call.
   - Extended `SophiaRouteResult` with `divertedFromRoute`, `clarificationThreshold`, and `isLowConfidenceClarification`.

2. **Low-Confidence Routes Ask Instead of Acting (`src/lib/server/sophia/intent-classifier.ts`)**:
   - Added `SophiaIntentClassifier.lowConfidenceClarification()` creating structured clarification proposals with options explaining the threshold gap.
   - Updated `SophiaIntentClassifier.route()`: when a candidate route has confidence strictly below its threshold, Sofia diverts to `'ask-clarify'` with `isLowConfidenceClarification: true` and `liveAi: false`.
   - Prevented self-divert loops on `ask-clarify`.

3. **Routing Calibration & Reliability Engine (`benchmark/router/calibration.ts`, `types.ts`)**:
   - Implemented `calculateBrierScore(samples)` evaluating $(1/N) \sum (p_i - y_i)^2$.
   - Implemented `calculateReliabilityCurve(samples, binCount = 5)` binning confidence into intervals, computing empirical accuracy, Expected Calibration Error (ECE), and Maximum Calibration Error (MCE).
   - Authored `runRouterCalibration()` generating durable report `benchmark/router/results/router-calibration-report.json`.

4. **CI Regression Gate (`benchmark/router/verify-ci-gate.ts`, `results/ci-baseline.json`)**:
   - Established authoritative baseline thresholds (`ci-baseline.json`).
   - Implemented `evaluateAgainstBaseline()` and `runVerifyCIGate()` verifying accuracy, Brier scores, calibration errors, and zero low-confidence leaks.

5. **Automated Verification Test Suite (`tests/sophia/g12_5_routing_evaluation_and_calibration.test.ts`)**:
   - 13 comprehensive tests covering mathematical formulas, threshold diversion, custom overrides, durable report generation, and CI gate checks.
