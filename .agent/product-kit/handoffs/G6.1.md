## Smallest-change ladder
Needed: Enables streamed open-topic conversation deltas across provider-neutral interfaces without coupling core reasoning to specific vendor SDKs.
Already in codebase: M1.1 batch ConversationProvider, ConversationAdapterRegistry, RealtimeModelProvider, and GeminiRealtimeProvider.
Platform or dependency: Native fetch, Web Streams API (ReadableStream getReader), TextDecoder, and Node.js EventEmitter.
Not built: Vendor-specific proprietary streaming protocols or specialized audio transport pipelines (reserved for G6.2).
Added: FakeRealtimeModelProvider test double for deterministic zero-network realtime testing, and streamText / streamConversationReply streaming adapter methods.

## What changed
1. Extended `ConversationProvider` interface in `src/lib/server/ai/types.ts` with optional `streamText(options, onDelta)`.
2. Implemented `streamText` in `FakeConversationProvider` (`src/lib/server/ai/providers/fake.ts`) breaking tokens into simulated chunks.
3. Implemented `streamText` in `GeminiConversationProvider` (`src/lib/server/ai/providers/gemini.ts`) using SSE `streamGenerateContent?alt=sse` parsing.
4. Added `executeStream` and exported `streamConversationReply` in `src/lib/server/ai/adapter.ts`, with circuit-breaking and automatic failover across the candidate chain.
5. Implemented `FakeRealtimeModelProvider` in `src/lib/server/live/providers/fake-provider.ts` for fast, offline, deterministic testing of realtime turns.
6. Refactored `src/lib/server/live/providers/index.ts` to register both Gemini and Fake providers, dynamically resolving the active provider via `getActiveRealtimeProviderId()` rather than hardcoding `'gemini'`.
7. Updated `src/app/api/realtime/turn/route.ts` to make `providerId` parameter optional and resolve through `getRealtimeProvider()` dynamically.
8. Authored automated regression suite `tests/sophia/g6_1_provider_neutral_streaming.test.ts` covering streaming, registry failover, realtime provider resolution, and zero vendor names in core logic.

## Why
Delivers gate step G6.1 ("Provider-neutral adapter for streamed open-topic conversation") by placing streamed token execution behind stable provider-neutral contracts, verifying real provider and fake provider compatibility, and ensuring zero vendor lock-in in core logic.
