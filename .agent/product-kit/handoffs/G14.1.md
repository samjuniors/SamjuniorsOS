## What changed
- Created `docs/architecture/ADR-0010-capability-registry-and-single-gateway.md`: Authoritative ADR analyzing GitLab's AI Catalog and OpenClaw's precedence model, ratifying the Single Execution Gateway and 5-pillar manifest schema.
- Created `src/types/capability.ts`: Zod schemas and TypeScript types for `CapabilityManifest` (permissions, side-effect class, trust tier, semantic version pin, cost model), `CapabilityInvocationRequest`, and `CapabilityInvocationResult`.
- Created `src/lib/server/capabilities/capability-registry.ts`: Authoritative registry enforcing manifest validation and the anti-shadowing invariant (prohibiting non-core capabilities from shadowing core capabilities or reserved namespaces).
- Created `src/lib/server/capabilities/capability-gateway.ts`: Single dispatch gateway evaluating `AutonomyPolicyEngine`, routing consequential mutations to `SideEffectAuthorizationGate` for founder approval, and recording append-only audit records to `InMemoryAuditStore`.
- Created `scripts/verify-capability-gateway.mjs`: Static AST/regex auditor scanning the codebase for direct unmediated capability execution bypasses.
- Created `tests/capabilities/g14_1_capability_gateway_static_check.test.ts`: 14 automated tests covering manifest schema validation, anti-shadowing, gateway dispatch, founder approval routing, destructive action denial, and static audit scanning.

## Why
Upholds the core architectural invariant of **ONE Sophia, ONE Authoritative State, Deterministic Governance** (`AGENTS.md` §3 & §4). Unvetted or ad-hoc tool execution creates severe security, prompt injection, and financial runaway risks.
