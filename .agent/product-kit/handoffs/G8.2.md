- `src/os/components/os/TodoDrawer.tsx`: Pull tab has `aria-label`, `aria-expanded`, `aria-controls="work-drawer-panel"`, drawer has `id="work-drawer-panel"` and `role="region"`, input and submit buttons labeled, owner selector uses `role="radiogroup"` / `role="radio"`, added Escape key listener.
- `src/os/components/os/ChatPanel.tsx`: Trigger button has `aria-label`, `aria-expanded`, `aria-haspopup="dialog"`, dialog has `role="dialog"`, contact bar uses `role="tablist"` / `role="tab"`, thread uses `role="log"` and `aria-live="polite"`, message inputs labeled, Escape dismisses.
- `src/os/components/os/PersonaModal.tsx`: Dialog has `role="dialog"`, `aria-modal="true"`, close buttons labeled, work pause/resume buttons labeled, disclosure uses `aria-expanded` and `aria-controls`, Escape key dismisses.
