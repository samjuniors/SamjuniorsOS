## Plan
1. Core Integrity & Anchor Engine (`src/lib/server/authorization/audit-integrity.ts`):
   - Define `AuditCheckpoint` with `ledgerId`, `formatVersion`, `sequence`, `recordHash`, `previousHash`, and `timestamp`.
   - Implement `IAuditAnchorProvider`, `FileAuditAnchorProvider` (immutable file checkpoints via exclusive write `wx`), and `InMemoryAuditAnchorProvider`.
   - Implement `AuditAnchorRegistry` and fail-closed head verification: detect tail truncation (sequence/hash mismatch) and ledger wipes.
2. Store Integration (`src/lib/server/authorization/approval-store.ts`):
   - Publish anchor checkpoints and verify chain head on every append and read in `PostgresAuditStore` and `InMemoryAuditStore`.
3. Spend Settings Fail-Closed Enforcement (`src/lib/server/sophia/spend-settings.ts`):
   - Audit write precedes setting persistence; if audit write fails, setting mutation aborts fail-closed and throws.
   - `getSpendAuditHistory` propagates `AuditIntegrityError` instead of masking errors.
4. Memory & Conversation Deletion Anti-Resurrection:
   - Verify Personal Mind deletion removes both durable-file copy and Prisma SQLite mirror (`tests/sophia/k2_personal_memory.test.ts`).
   - Verify conversation deletion tombstone anti-resurrection (`tests/sophia/m1_batch2_conversation_deletion.test.ts`).
5. Comprehensive Test Suite:
   - Author 8-phase test suite in `tests/sophia/g3_6_audit_integrity.test.ts` covering concurrency, interior tampering, tail truncation, ledger wipe, anchor gaps, legacy rejection, spend-settings fail-closed, and authoritative Prisma store.
What will not be done: Will not introduce paid cloud services, third-party packages, or unnecessary database schema changes.

## What changed
1. `src/lib/server/authorization/audit-integrity.ts`:
   - Added `AuditCheckpoint`, `AuditAnchorMismatchError`, `IAuditAnchorProvider`, `InMemoryAuditAnchorProvider`, `FileAuditAnchorProvider`, and `AuditAnchorRegistry`.
   - `FileAuditAnchorProvider` enforces create-if-absent immutability via `wx` flag, sequence gap validation, and read-back confirmation.
   - Implemented `verifyHead` and `verifyHeadSync`: compares ledger head with trusted anchor to detect tail/suffix truncation, ledger wipes, and hash mismatches.
   - Enhanced `verifyAuditChain` and `appendAuditChainRecord` with anchor validation options.
2. `src/lib/server/authorization/approval-store.ts`:
   - Integrated anchor publishing and validation into `PostgresAuditStore.record`, `PostgresAuditStore.list`, `InMemoryAuditStore.record`, `InMemoryAuditStore.list`, and `InMemoryAuditStore.loadFromDurableStorage`.
   - Updated `clear()` to clear test anchors when permitted.
3. `src/lib/server/sophia/spend-settings.ts`:
   - Enforced fail-closed ordering: `logAuditRecord` runs before `this.persistSettings(this.settings)`. If audit logging fails, setting change is aborted and throws immediately.
   - Removed error swallowing in `logAuditRecord`.
   - Updated `getSpendAuditHistory` to propagate `AuditIntegrityError`.
4. `tests/sophia/g3_6_audit_integrity.test.ts`:
   - Authored comprehensive 8-phase test suite verifying:
     - Phase 1: 8 concurrent local appends produce one contiguous sequence with disk anchor checkpoints.
     - Phase 2: Interior record modification fails closed (hash mismatch).
     - Phase 3: Suffix / tail truncation fails closed (`AuditAnchorMismatchError`).
     - Phase 4: Ledger wipe fails closed (`AuditAnchorMismatchError`).
     - Phase 5: Anchor sequence gap and mutation detection fails closed.
     - Phase 6: Legacy unsealed history cannot be silently resealed (`LegacyAuditHistoryError`).
     - Phase 7: Spend cap fails closed when audit trail is compromised.
     - Phase 8: Authoritative Prisma audit store records and verifies chained records with tail truncation protection.
5. `tests/sophia/k2_personal_memory.test.ts`:
   - Enabled SQLite database connection by default to ensure Prisma mirror deletion assertions execute (T18a and T18). Both durable file and Prisma rows are confirmed deleted.
6. `scripts/seed-audit-anchors.ts`:
   - Utility script to anchor pre-existing audit records.

## Why
Fulfills Gate G3.6 exit criteria:
- **Tamper test fails closed:** Interior modification, sequence gaps, legacy unsealed history, ledger wipes, and tail truncation ALL fail closed and throw `AuditIntegrityError` / `AuditAnchorMismatchError`.
- **Deletion leaves no resurrectable copy in any store:**
  - Conversation deletion: verified by 52 passing assertions in `tests/sophia/m1_batch2_conversation_deletion.test.ts` (tombstone anti-resurrection, Prisma reconciliation, cross-founder isolation).
  - Personal Mind deletion: verified by 21 passing assertions in `tests/sophia/k2_personal_memory.test.ts` (durable-file copy and Prisma mirror row are both confirmed deleted).
- **Hash-chained tamper-evident audit:**
  - SHA-256 canonical hashing links previous and current records.
  - Independent `FileAuditAnchorProvider` acts as the trusted external head witness per ADR 0012, preventing tail truncation.
