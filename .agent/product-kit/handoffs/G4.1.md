# G4.1: Company Brain as the single read and write path; retire parallel legacy paths

Exit evidence required: Static and runtime proof that no code path reads or writes company state outside the Brain; old paths removed.

## Plan
1. Create `src/lib/server/brain/company-brain.ts` (and `src/lib/server/brain/index.ts`) establishing `CompanyBrain` as the authoritative single read/write interface for Company State, Company Knowledge, Company Precedents (Memory), Decisions, and Epistemic Facts.
2. Encapsulate `CompanyStateStore` behind `CompanyBrain`: expose operational state getters (`getInitiatives`, `getFinancialMetrics`, `getProducts`, `getCustomers`, `getAttentionItems`, `getEmployees`, `getDecisions`, `queryState`) and atomic mutation setters (`setInitiatives`, `updateFinancialMetrics`, `updateProducts`, `updateCustomers`, `updateAttentionItems`, `recordDecision`).
3. Retire parallel legacy paths:
   - Retire the unpersisted module-level arrays (`serverRecentIntelligence`, `serverEngineeringIntelligence`) in `CompanyContextProvider` and route intelligence capture through `CompanyBrain` with durable evidence references in `company_intelligence.json`.
   - Refactor `CompanyContextProvider` into a pure presentation formatter delegating all operational state directly to `CompanyBrain`.
   - Update `SophiaContextAssembler` (slice 1), `SophiaServerGateway` (domain: company_metrics), and `greeting.ts` to read operational state exclusively via `CompanyBrain`.
4. Ensure `spend-settings.ts` does not perform un-coordinated direct writes to `company_state`: route spend settings queries and persistence cleanly through `CompanyBrain` / `CompanyStateStore`.
5. Add comprehensive static and runtime verification suite `tests/platform/company_brain_single_path.test.ts`:
   - Static AST / grep proof verifying zero server code paths perform direct unmediated writes or reads to company state outside `CompanyBrain`.
   - Runtime test verifying that updates via `CompanyBrain` propagate atomically across all projections, persist across simulated restarts, maintain personal mind isolation, and enforce fail-closed authority.
6. What will NOT be done: No schema changes, no new external dependencies, no modification of personal mind invariants or authorization gates.

## What changed
- Created `src/types/brain.ts` defining `ICompanyBrain` and `FullCompanyContext`. `ICompanyBrain` extends `ICompanyStateStore` for seamless backward-compatibility.
- Created `src/lib/server/brain/company-brain.ts` and `src/lib/server/brain/index.ts` implementing the singleton `CompanyBrain` managing operational state, company knowledge, precedents/memories, decisions, epistemic facts, and durable intelligence.
- Updated `src/lib/server/state/state-store.ts` adding collection-locked persistence for products, customers, attention items, and employees (`updateProducts`, `updateCustomers`, `updateAttentionItems`, `updateEmployees`).
- Refactored `src/lib/server/context/company-context.ts`: removed shadow in-memory module-level arrays (`serverRecentIntelligence`, `serverEngineeringIntelligence`); delegated all operational state, constitution, and intelligence to `CompanyBrain`.
- Updated `src/lib/server/tools/providers/github.ts`: routed engineering intelligence recording directly through `CompanyBrain`.
- Updated `src/lib/server/sophia/context-assembly.ts`: slice 1 reads operational telemetry from `CompanyBrain`.
- Updated `src/lib/server/sophia/server-gateway.ts`: `company_metrics` reads from `CompanyBrain`.
- Updated `src/lib/server/sophia/greeting.ts`: reads metrics from `CompanyBrain`.
- Updated `src/lib/server/context/context-assembly.ts` and `src/lib/server/context/context-retrieval.ts`: default `stateStore` parameter to `CompanyBrain.getInstance()`.
- Created dedicated verification suite `tests/platform/company_brain_single_path.test.ts` testing static AST proof, runtime operational mutations, process restart persistence, and personal mind segregation.

## Why
Eliminates volatile shadow state arrays and fragmented direct accesses to company state files. Guarantees that all company state operations (operational telemetry, knowledge, memory, decisions, epistemic facts) pass through the single authoritative Company Brain path with collection-locked durability and strict personal mind isolation.
