# SamJuniorsOS — Core V5 Prototype (Conversational Operating Center)

## Overview
Core V5 is a complete paradigm shift away from dashboard and card-centric UIs. It places the founder in a dark, serene environment with **one intelligent Core / light presence as the main character**.

## Key Concepts

### 1. Dark Room + Single Light Presence
- Ultra-dark ambient space (`#020408`) where the procedural Core acts as the sole luminous entity.
- The Core illuminates the floor plane and ambient space with physical radial gradients and vocal modulations.

### 2. Dialogue-First Interface
- Core speaks directly to the founder through clean, living typography.
- Natural language intent parsing for:
  - *"What needs my attention?"* (surfaces pending authority decisions)
  - *"Review positioning"* (initiates active synthesis work)
  - *"Company health"* (reports system baselines)
  - *"Check on Sophia and Thorne"* (governed workforce status)
- Real-time interruption: Issuing a new directive while Core is working smoothly interrupts and redirects the work.

### 3. Progressive Disclosure (Expand Around the Event)
- The default screen shows almost nothing except the Core, its speech line, and the conversational input.
- The event expansion surface expands dynamically only when:
  - **Active Work**: Compact step ribbon with real-time source evaluations and steering controls.
  - **Authority Decision**: Focused authority spotlight requiring authenticated founder approval, redirect, or rejection.
  - **Outcome**: Concrete result summary with evidence and provenance inspection links.
  - **Blocked State**: Epistemic invariant halt diagnostic.

### 4. Edge Navigation & OS Slide-Over Drawer
- Tiny edge triggers (bottom bar and top header) prevent dashboard clutter.
- Switching to **Manual Mode** or pressing `⌘ OS` opens an obsidian slide-over drawer exposing all 7 governed OS modules:
  - `Company State`
  - `Workforce`
  - `Decisions`
  - `Research`
  - `Activity`
  - `Audit`
  - `Messenger`
- Credit exhaustion honestly gates natural language synthesis while preserving full unhindered access to all 7 modules via Manual mode.

### 5. Honest Demo Safety
- Permanent watermark: `DEMO STATE · NO LIVE COMPANY DATA CONNECTED`.
- Zero fabricated metrics, fake revenue, or fictitious employees.
