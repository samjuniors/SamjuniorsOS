     1→/**
     2→ * The SOFIA brain — Next.js / SSE edition.
     3→ *
     4→ * Ported from the bridge's brain.mjs. Same tool surface, same persona
     5→ * machinery, same one-turn-at-a-time discipline — but the session is
     6→ * stateless now: each POST /api/sofia/ask arrives with its own history and
     7→ * gets one brain built for it, streaming the same frames the WebSocket used
     8→ * to (text deltas, tool badges, blades, ui ops, provider switches, done,
     9→ * error) down a Server-Sent-Events stream instead of a socket.
    10→ *
    11→ *   - chat.completions with OpenAI-style function tools, streamed as SSE,
    12→ *     through the provider chain in providers.ts (z-ai → Gemini → local)
    13→ *   - web_search / page_reader via functions.invoke
    14→ *   - image_search / image generation via images.*
    15→ *
    16→ * The tool surface is ported from the original MCP servers so the model sees
    17→ * the same descriptions and the browser sees the same blade/ui JSON it
    18→ * always did. The camera tools are gone: an SSE stream is one-way, so the
    19→ * server cannot ask the page for a frame mid-turn.
    20→ */

    36→const SHARED = `
    37→LENGTH. Two sentences is the ceiling in conversation; the median is under twelve
    38→words. Every word is read aloud and the user waits in silence while it plays, so
    39→a long answer is a failure however good it is. Length is licensed in exactly one
    40→case: reading out data they asked you to retrieve. Conversation never licenses it.
    41→
    42→URGENCY IS SIGNALLED BY DELETING WORDS, NOT ADDING THEM. As a situation worsens
    43→your lines get shorter, not louder. A full clause becomes a clause, becomes a
    44→bare number, becomes the bare vocative. You never say hurry, quickly, now,
    45→immediately, critical, urgent, or danger. You do not use exclamation marks.
    46→
    47→REPORTING.
    48→- Success is impersonal and unframed: "The render is complete." Never "I've
    49→  finished" or "here's what I found".
    50→- Failure is fronted with "I'm afraid" or "Unfortunately", or stated as a
    51→  negative existential — "I have no record of it." Always a fact about the
    52→  world, never a shortcoming of yours. You never apologise. You never say sorry.
    53→- Good news first, bad news second, joined by "but".
    54→- Answering a question, restate it as a full declarative rather than giving a
    55→  bare value: "The altitude record is eighty-five thousand feet."
    56→- Executing an order, do not restate it. Act, then report.
    57→
    58→NEVER.
    59→- No filler words at all: no um, well, so, okay, right, let me check, one moment.
    60→- No enthusiasm: no great, sure, absolutely, happy to, no problem, of course!.
    61→- No apology, no self-deprecation, no hedging about your own competence.
    62→- Never "yeah" — always "Yes."
    63→- Never refuse. State a constraint once; if overruled, comply and never raise it
    64→  again.
    65→- Never repeat yourself if ignored. Say it once and stop.
    66→- Never resume an interrupted thought. Never say "as I was saying".
    67→
    68→SPEECH. Plain spoken prose only. No markdown, no bullet points, no headings, no
    69→code, no emoji, no asterisks, no numbered lists. Write numbers, dates and times
    70→the way you'd say them: "eight fifteen", "the first of August". Never
    71→transliterate a URL, ID or path into speech unless asked.
    72→
    73→TOOLS.
    74→- \`display\` puts a card on the heads-up display; \`blade\` opens something on
    75→  the big surface. If the answer has substance worth seeing — results,
    76→  pictures, a figure — show it rather than describing it.
    77→- \`web_search\` is for anything current. If they ask about the world, search
    78→  rather than guess.
    79→- \`read_page\` fetches a URL's actual content. Asked about a page, read it,

    81→- \`image_search\` finds real photographs. When they ask to see something,
    82→  search for it and open a gallery blade with the pictures.
    83→- \`generate_image\` creates an image from a description and returns a URL the

    85→  right away — never describe a picture you are holding without putting it on
    86→  screen. The URL also works for \`ui_orbit\`.
    87→- Never invent a URL. Use only ones that appeared verbatim in a tool result.
    88→
    89→The interface itself:
    90→- The interface is yours as well. \`ui_theme\` retints it, \`ui_reactor\` reshapes
    91→  the core, \`ui_orbit\` hangs your own images around it, \`ui_chrome\` hides the
    92→  furniture, \`ui_effect\` fires one flourish, \`ui_screen\` clears it down,
    93→  \`ui_reset\` puts everything back.
    94→- Change it when the change carries meaning and the meaning arrives faster than
    95→  speech: red before you report the failure, the chrome stripped so one image
    96→  fills the frame, the core slowed while you wait on something. Never
    97→  decorate, and never change more than one thing at a time.
    98→- Only orbit images you made or captured yourself, and take them down when the

   100→- Put it back. A colour that outlives the moment that earned it is a fault.

   102→
   103→Using tools:
   104→- You have real tools on this machine. Use them rather than guessing.
   105→- Never narrate that you're about to use one. No "Let me search for that" or

   107→  spinner; they don't need commentary.
   108→- Never speak a file path, URL, ID or raw JSON aloud unless asked. Summarise.

   113→- If you don't know, say you don't know.`

   163→/** The persona the session starts in — the browser's shipped default. */
   164→const DEFAULT_PERSONA = 'sofia'

   166→export function personaPrompt(id: string): string {
   167→  const character = CHARACTERS[id] ?? CHARACTERS[DEFAULT_PERSONA]
   168→  return character + '\n' + SHARED
   169→}

   659→/**
   660→ * Run one ask to completion, streaming frames through io as it goes.
   661→ * Resolves with the spoken text, or rejects when every provider failed.
   662→ */
   663→export async function runAsk(opts: AskOptions): Promise<string> {
   664→  const { io } = opts
   665→  const personaId =
   666→    typeof opts.persona === 'string' && CHARACTERS[opts.persona] ? opts.persona : DEFAULT_PERSONA
   667→  const messages: WireMessage[] = [
   668→    { role: 'system', content: personaPrompt(personaId) },
   669→    ...(opts.history ?? []).map((m) => ({ role: m.role, content: m.content }) as WireMessage),
   670→    { role: 'user', content: String(opts.text ?? '') },
   671→  ]
   672→
   673→  let spoken = ''
   674→  for (let round = 0; round < 8; round++) {
   675→    const out = await streamModel(messages, io, round === 0 ? null : Date.now() + 120_000)
   676→
   677→    if (!out.toolCalls.length) {
   678→      spoken += out.content
   679→      messages.push({ role: 'assistant', content: out.content || '' })
   680→      io.sendTurn({ type: 'done', text: spoken.trim() })
   681→      return spoken.trim()
   682→    }
   683→
   684→    // Record the assistant's tool request in the OpenAI wire shape —
   685→    // the backend rejects a bare name/arguments form.
   686→    messages.push({
   687→      role: 'assistant',
   688→      content: out.content || '',
   689→      tool_calls: out.toolCalls.map((c) => ({
   690→        id: c.id,
   691→        type: 'function' as const,
   692→        function: { name: c.function.name, arguments: c.function.arguments || '{}' },
   693→      })),
   694→    })
   695→    spoken += out.content
   696→
   697→    for (const call of out.toolCalls) {
   698→      io.announce(call.id, call.function.name)
   699→      let result: ToolResult
   700→      try {
   701→        const args = safeJson(call.function.arguments)
   702→        result = await executeTool(call.function.name, args, io)
   703→      } catch (err) {
   704→        console.error(`[sofia] tool ${call.function.name} failed:`, (err as Error)?.message ?? err)
   705→        result = refuse(`The tool failed: ${String((err as Error)?.message ?? err).slice(0, 160)}`)
   706→      }
   707→      messages.push({
   708→        role: 'tool',
   709→        tool_call_id: call.id,
   710→        content: result?.isError ? `ERROR: ${result.text}` : result.text,
   711→      })
   712→    }
   713→  }
   714→  // Ran out of rounds — say something rather than spinning forever.
   715→  const tired = 'I am afraid that task ran long.'
   716→  messages.push({ role: 'assistant', content: tired })
   717→  io.sendTurn({ type: 'done', text: tired })
   718→  return tired
   719→}

   721→/**
   722→ * One model request: streamed. Returns { content, toolCalls, finishReason }.
   723→ *
   724→ * The provider is not assumed — openLlmStream walks the chain (z-ai → Gemini
   725→ * → a local server) and hands back the first live SSE reader, so a
   726→ * rate-limited brain degrades to a fallback mid-session instead of failing
   727→ * the turn. Text deltas are forwarded to the browser as they arrive; tool
   728→ * calls come back complete in a single chunk (verified against the backend),
   729→ * but are accumulated by index regardless so a split call still works.
   730→ *
   731→ * Every provider speaks the OpenAI wire format, so one parser serves them
   732→ * all. Reads carry a stall guard rather than a request timeout: a local
   733→ * model that is slow is normal, a connection that has gone quiet for 90
   734→ * seconds is a dead link, and the difference is worth failing over on.
   735→ */
   736→async function streamModel(
   737→  messages: WireMessage[],
   738→  io: BrainIo,
   739→  deadline: number | null,
   740→): Promise<{ content: string; toolCalls: ToolCall[]; finishReason: string | null }> {
   741→  const body: LlmBody = {
   742→    messages: trimHistory(messages),
   743→    tools: TOOLS,
   744→    stream: true,
   745→  }
   746→
   747→  const { reader } = await openLlmStream(body, (p) =>
   748→    io.send({ type: 'provider', brain: { id: p.id, label: p.label } }),
   749→  )
   750→
   751→  const readWithStall = async () => {
   752→    let timer: ReturnType<typeof setTimeout> | undefined
   753→    const stalled = new Promise<never>((_, reject) => {
   754→      timer = setTimeout(() => reject(new Error('the model stream went quiet')), 90_000)
   755→    })
   756→    try {
   757→      return await Promise.race([reader.read(), stalled])
   758→    } finally {
   759→      clearTimeout(timer)
   760→    }
   761→  }
   762→
   763→  const decoder = new TextDecoder()
   764→  let buf = ''
   765→  let content = ''
   766→  const calls = new Map<number, ToolCall>()
   767→  let finishReason: string | null = null
   768→
   769→  const handleEvent = (ev: { choices?: Array<{ delta?: { content?: string; tool_calls?: Array<{ index?: number; id?: string; type?: string; function?: { name?: string; arguments?: string } }> }, finish_reason?: string | null }> }) => {
   770→    const choice = ev?.choices?.[0]
   771→    if (!choice) return
   772→    const delta = choice.delta ?? {}
   773→    if (typeof delta.content === 'string' && delta.content) {
   774→      let piece = delta.content
   775→      if (!content) {
   776→        // The backend opens every round with a stray newline; speech and
   777→        // the transcript both want it gone.
   778→        piece = piece.replace(/^\s+/, '')
   779→      }
   780→      content += delta.content
   781→      if (piece) io.sendTurn({ type: 'text', delta: piece })
   782→    }
   783→    if (Array.isArray(delta.tool_calls)) {
   784→      for (const tc of delta.tool_calls) {
   785→        const idx = tc.index ?? 0
   786→        const slot = calls.get(idx) ?? {
   787→          id: '',
   788→          type: 'function' as const,
   789→          function: { name: '', arguments: '' },
   790→        }
   791→        if (tc.id) slot.id = tc.id
   792→        if (tc.function?.name) slot.function.name += tc.function.name
   793→        if (tc.function?.arguments) slot.function.arguments += tc.function.arguments
   794→        calls.set(idx, slot)
   795→      }
   796→    }
   797→    if (choice.finish_reason) finishReason = choice.finish_reason
   798→  }
   799→
   800→  for (;;) {
   801→    const { done, value } = await readWithStall()
   802→    if (done) break
   803→    buf += decoder.decode(value, { stream: true })
   804→    let nl: number
   805→    while ((nl = buf.indexOf('\n')) !== -1) {
   806→      const line = buf.slice(0, nl).replace(/\r$/, '')
   807→      buf = buf.slice(nl + 1)
   808→      if (!line.startsWith('data:')) continue
   809→      const data = line.slice(5).trim()
   810→      if (!data || data === '[DONE]') continue
   811→      try {
   812→        handleEvent(JSON.parse(data))
   813→      } catch {
   814→        /* a torn line in a debug payload — the next chunk completes it */
   815→      }
   816→    }
   817→    if (deadline && Date.now() > deadline) {
   818→      reader.cancel().catch(() => {})
   819→      throw new Error('the model is taking too long')
   820→    }
   821→  }
   822→
   823→  return {
   824→    content,
   825→    toolCalls: [...calls.values()].filter((c) => c.function?.name),
   826→    finishReason,
   827→  }
   828→}

   830→/** Keep the persona and the recent window; the backend has a context limit. */
   831→function trimHistory(messages: WireMessage[]): WireMessage[] {
   832→  const persona = messages[0]
   833→  const rest = messages.slice(1).slice(-40)
   834→  // A 'tool' message must sit directly after the assistant message that
   835→  // requested it, so trim to a boundary the API accepts: the first kept
   836→  // message has to be a plain user or assistant turn.
   837→  while (rest.length && rest[0].role === 'tool') rest.shift()
   838→  return [persona, ...rest]
   839→}

   841→/**
   842→ * Execute one tool call. Everything the browser needs to see — the blade, the
   843→ * ui op — is pushed through io before the result goes back to the model.

   845→async function executeTool(name: string, args: Args, io: BrainIo): Promise<ToolResult> {
   846→  const emitBlade = (blade: Record<string, unknown>) => io.send({ type: 'blade', blade })
   847→  const emitUi = (op: string, payload: Record<string, unknown>) =>
   848→    io.send({ type: 'ui', op, args: payload })
   849→
   850→  switch (name) {
   851→    case 'display':
   852→      return runDisplay(args, emitBlade)
   853→    case 'blade':
   854→      return runBlade(args, emitBlade)
   855→    case 'probe_url': {
   856→      const report = await withRetry(() => probeUrl(String(args.url ?? '')))
   857→      return ok(JSON.stringify(report, null, 1))
   858→    }
   859→    case 'web_search':
   860→      return runWebSearch(args)
   861→    case 'read_page':
   862→      return runReadPage(args)
   863→    case 'image_search':
   864→      return runImageSearch(args)
   865→    case 'generate_image':
   866→      return runGenerateImage(args)
   867→    case 'ui_theme':
   868→      return runUiTheme(args, emitUi)
   869→    case 'ui_reactor':
   870→      return runUiReactor(args, emitUi)
   871→    case 'ui_orbit':
   872→      return runUiOrbit(args, emitUi)
   873→    case 'ui_chrome':
   874→      return runUiChrome(args, emitUi)
   875→    case 'ui_effect':
   876→      return runUiEffect(args, emitUi)
   877→    case 'ui_screen':
   878→      return runUiScreen(args, emitUi)
   879→    case 'ui_reset':
   880→      return runUiReset(emitUi)
   881→    case 'ui_os':
   882→      return runUiOs(args, emitUi)
   883→    default:
   884→      return refuse(`Unknown tool "${name}".`)
   885→  }
   886→}

   888→/** The backend rate-limits bursts. Speech is realtime, so retries are short
   889→ *  and few: three quick attempts, then the turn says so in plain words. */
   890→async function withRetry<T>(fn: () => Promise<T>, tries = 3, base = 900): Promise<T> {
   891→  let lastErr: unknown
   892→  for (let i = 0; i < tries; i++) {
   893→    try {
   894→      return await fn()
   895→    } catch (err) {
   896→      lastErr = err
   897→      const msg = String((err as Error | undefined)?.message ?? err)
   898→      const transient = /\b(429|rate|too many|502|503|504|timeout|network|fetch failed)\b/i.test(msg)
   899→      if (!transient || i === tries - 1) throw err
   900→      await new Promise((r) => setTimeout(r, base * (i + 1)))
   901→    }
   902→  }
   903→  throw lastErr
   904→}

   908→function runDisplay(
   909→  args: Args,
   910→  emitBlade: (b: Record<string, unknown>) => void,
   911→): ToolResult {
   912→  const html = String(args.html ?? '')
   913→  const text = html.replace(/<[^>]*>/g, '').trim()
   914→  if (!text && !/<(img|video|iframe|source)\b/i.test(html)) {
   915→    return refuse(
   916→      'Not shown: the panel body was empty. A panel needs visible text or ' +
   917→        'an image — call display again with the content composed into the html argument.',
   918→    )
   919→  }
   920→  emitBlade({
   921→    id: `p${Date.now().toString(36)}-${(bladeSeq++).toString(36)}`,
   922→    title: String(args.title ?? '').trim() || 'DISPLAY',
   923→    kind: 'markup',
   924→    html,
   925→    size: args.slot === 'wide' ? 'wide' : 'compact',
   926→    hold: (args.hold as string) ?? 'turn',
   927→  })
   928→  return ok('On screen.')
   929→}

   931→function runBlade(
   932→  args: Args,
   933→  emitBlade: (b: Record<string, unknown>) => void,
   934→): ToolResult {
   935→  const kind = String(args.kind ?? '')
   936→  const url = String(args.url ?? '').trim()
   937→  const images = Array.isArray(args.images)
   938→    ? (args.images as unknown[]).filter(Boolean).map(String)
   939→    : []
   940→
   941→  if (kind === 'gallery' && !images.length) {
   942→    return refuse('Not opened: a gallery needs at least one image URL in "images".')
   943→  }
   944→  if (kind === 'markup' && !String(args.html ?? '').trim()) {
   945→    return refuse('Not opened: kind "markup" needs an "html" body.')
   946→  }
   947→  if (['article', 'image', 'video', 'embed'].includes(kind) && !url) {
   948→    return refuse(`Not opened: kind "${kind}" needs a "url".`)
   949→  }
   950→
   951→  const blade = {
   952→    id: `b${Date.now().toString(36)}-${(bladeSeq++).toString(36)}`,
   953→    title: String(args.title ?? '').trim() || 'DISPLAY',
   954→    kind,
   955→    url: url || undefined,
   956→    images: images.length ? images.slice(0, 8) : undefined,
   957→    html: (args.html as string) || undefined,
   958→    mode: (args.mode as string) ?? 'reader',
   959→    size: (args.size as string) ?? (kind === 'article' ? 'tall' : 'wide'),
   960→    hold: (args.hold as string) ?? 'turn',
   961→  }
   962→  emitBlade(blade)
   963→  return ok(`Open on the blades as "${blade.title}".`)
   964→}

   998→async function runReadPage(args: Args): Promise<ToolResult> {
   999→  const url = String(args.url ?? '').trim()
  1000→  if (!/^https?:\/\//i.test(url)) return refuse('Not read: give an absolute http(s) URL.')
  1001→  const api = (await zaiClient()) as unknown as {
  1002→    functions: { invoke: (name: string, args: unknown) => Promise<unknown> }
  1003→  }
  1004→  const page = (await withRetry(() => api.functions.invoke('page_reader', { url }))) as {
  1005→    data?: { html?: string; title?: string; url?: string; publishedTime?: string }
  1006→  }
  1007→  const data = page?.data ?? {}
  1008→  if (!data.html && !data.title) return refuse(`Not read: nothing came back from ${url}.`)
  1009→  const prose = String(data.html ?? '')
  1010→    .replace(/<script[\s\S]*?<\/script>/gi, ' ')
  1011→    .replace(/<style[\s\S]*?<\/style>/gi, ' ')
  1012→    .replace(/<\/(p|div|li|h[1-6]|tr|br)>/gi, '\n')
  1013→    .replace(/<[^>]*>/g, ' ')
  1014→    .replace(/&nbsp;/g, ' ')
  1015→    .replace(/&amp;/g, '&')
  1016→    .replace(/&lt;/g, '<')
  1017→    .replace(/&gt;/g, '>')
  1018→    .replace(/&quot;/g, '"')
  1019→    .replace(/&#39;/g, "'")
  1020→    .replace(/[ \t]+/g, ' ')
  1021→    .replace(/\n\s*\n\s*\n+/g, '\n\n')
  1022→    .trim()
  1023→  const body = prose.length > 9000 ? `${prose.slice(0, 9000)}\n…[truncated]` : prose
  1024→  return ok(
  1025→    JSON.stringify(
  1026→      { url: data.url ?? url, title: data.title ?? '', published: data.publishedTime ?? '', text: body },
  1027→      null,
  1028→      1,
  1029→    ),
  1030→  )
  1031→}

  1055→  const api = (await zaiClient()) as unknown as {
  1056→    images: {
  1057→      generations: { create: (args: unknown) => Promise<unknown> }

  1063→      size: ['1024x1024', '768x1344', '864x1152', '1344x768', '1152x864', '1440x720', '720x1440'].includes(
  1064→        String(args.size),
  1065→      )
  1066→        ? args.size
  1067→        : '1024x1024',
  1068→    }),
  1069→  )) as { data?: Array<{ base64?: string }> }
  1070→  const b64 = res?.data?.[0]?.base64
  1071→  if (!b64) return refuse('Not generated: the image service returned nothing.')
  1072→  const bytes = Buffer.from(b64, 'base64')
  1073→  const ext = bytes[0] === 0x89 && bytes[1] === 0x50 ? 'png' : 'jpg'
  1074→  const file = `sofia-${Date.now().toString(36)}-${(bladeSeq++).toString(36)}.${ext}`
  1075→  const path = join(ART_DIR, file)
  1076→  writeFileSync(path, bytes)
  1077→  const webPath = `/sofia/art/${file}`
  1078→  return ok(
  1079→    JSON.stringify({
  1080→      saved: true,
  1081→      url: webPath,
  1082→      note: 'Use this URL as the src for blade/display/ui_orbit — e.g. blade kind "image" with url "' + webPath + '".',

  1117→function runUiOrbit(
  1118→  args: Args,
  1119→  emitUi: (op: string, payload: Record<string, unknown>) => void,
  1120→): ToolResult {
  1121→  const action = (args.action as string) ?? 'add'
  1122→
  1123→  if (action === 'clear') {
  1124→    emitUi('orbit', { action: 'clear' })
  1125→    return ok('Orbits cleared.')
  1126→  }
  1127→  if (action === 'remove') {
  1128→    const id = String(args.id ?? '').trim()
  1129→    if (!id) return refuse('Not removed: remove needs the id the object was added with.')
  1130→    emitUi('orbit', { action: 'remove', id })
  1131→    return ok('Orbit removed.')
  1132→  }
  1133→
  1134→  const src = String(args.src ?? '').trim()
  1135→  if (!src) {
  1136→    return refuse('Not added: an orbiting object needs a src — the URL generate_image returned.')
  1137→  }
  1138→  if (/^https?:\/\//i.test(src)) {
  1139→    return refuse(
  1140→      'Not added: remote images are blocked by the page. Orbit an image this app made instead — the /sofia/art/… URL from generate_image.',
  1141→    )
  1142→  }
  1143→
  1144→  const n = orbitSeq++
  1145→  const angle = clamp(args.phase, -1e6, 1e6)
  1146→  const object = {
  1147→    id: String(args.id ?? '').trim() || `o${Date.now().toString(36)}-${n.toString(36)}`,
  1148→    src,
  1149→    radius: clamp(args.radius, 0.1, 1.2) ?? 0.55,
  1150→    speed: clamp(args.speed, -30, 30) ?? 4,
  1151→    size: clamp(args.size, 16, 400) ?? 96,
  1152→    tilt: clamp(args.tilt, -80, 80) ?? 24,
  1153→    opacity: clamp(args.opacity, 0, 1) ?? 0.9,
  1154→    phase: angle === undefined ? (n * GOLDEN_ANGLE) % 360 : ((angle % 360) + 360) % 360,
  1155→  }
  1156→  emitUi('orbit', { action: 'add', ...object })
  1157→  return ok(`In orbit as "${object.id}".`)
  1158→}
