## Archive policy

Keep source material, dates, accepted decisions and provenance. Mark supersession at an index or document header instead of silently replacing a finding. Before moving a heavily referenced file, audit inbound links and relative links, then provide a compatibility pointer. No file should be permanently deleted or deduplicated solely because it appears stale or repetitive.

See the [branch documentation audit](../audit/2026-10-23-kit-integration-documentation-audit.md) for dispositions and remaining verification gates.
